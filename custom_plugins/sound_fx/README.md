# Sound FX

Play custom MP3/WAV/OGG sounds on race events, plus a personal sound per
pilot (name callout) on laps, holeshot, finish and win.

Manage sounds from **Settings → Sound FX**. Sounds play in every connected
browser; open `/sound_fx/player` on any device to use it as a dedicated
speaker; optional playback on the server audio output (`mpg123` etc.).

Full documentation: https://github.com/izicubed/RotorHazard-Sound-FX
